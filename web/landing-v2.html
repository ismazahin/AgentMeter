LLM efficiency benchmark

See what each agent costs to run, flow by flow.

AgentMeter runs open-source LLMs through a four-agent network triage pipeline on a rented GPU, all at the same 4-bit NF4, and records latency, VRAM, tokens, cost and energy for every step.

Multi-agent pipelines pass work from agent to agent, and every hand-off is paid for in tokens, time and memory. AgentMeter puts a number on each of them.

Method

Built so the comparison stays fair.

The pipeline is the test subject. The contribution is the measurement harness, the per-agent instrumentation and the comparison method.

4-bit

Same quantization for all

Every model loads as 4-bit NF4. Extra models are verified on the GPU first, so none is benchmarked at a different precision.

SAW

Weighted, tested ranking

Simple Additive Weighting ranks models on latency, VRAM, tokens and cost, with weight presets you can try. Differences are checked with Kruskal-Wallis and Dunn tests.

score = Σ wᵢ · normalised costᵢ
