What changed

Going from 2 to 10 agents roughly tripled the time per flow for both models, because every extra agent re-reads all the earlier answers: re-sent context grew from 0.4k to 5.1k tokens per flow. Triage accuracy moved by 3 points or less, a gap the test calls a tie.

8-bit used about a third more GPU memory than 4-bit and was slower at every agent count, so on this GPU it costs more without a measured accuracy gain.
