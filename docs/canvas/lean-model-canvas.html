Problem

  1. Latency piles up and no one can see which agent causes it. Agents run one after another, so their delays add up. Only the whole pipeline is timed, so the slow agent cannot be found and fixed while attacks spread.
  2. Existing benchmarks do not fit agentic security work. They test single-shot, general tasks and report accuracy and cost separately, so SOC teams have no reference for choosing an open-source LLM.
  3. Memory and token use is reported only as one total. Two models with similar totals can spend very differently inside. Context re-sent at every hand-off uses most of the tokens and goes unseen.

EXISTING ALTERNATIVES

  • General LLM leaderboards that score single-shot accuracy only (Open LLM Leaderboard, LMArena)
  • Agent benchmarks that check task completion, not resource cost
  • Inference benchmarks (MLPerf, vLLM) that time the whole model call, not each agent
  • Hand-timed runs and spreadsheets that report one pipeline total

Solution

  1. Per-agent benchmarking tool. Instruments every step of an agentic triage pipeline that handles the threats an IDS has detected, with any number of agents, and assigns response time, memory and tokens to each agent.
  2. Monitoring and analysis module. Captures per-agent and end-to-end telemetry and combines triage accuracy and resource cost into one composite score ranking.
  3. What-if experiments. Runs each open-source LLM at 4, 8 and 16-bit and with 1 to 10 agents on the same alerts, and charts how speed, memory, tokens, accuracy and cost change.

Unique Value Proposition

Find the open-source LLM that triages IDS-detected threats at the lowest resource cost, with that cost broken down per agent.

The IDS detects the threats. AgentMeter runs each candidate LLM through the same triage pipeline on those alerts and shows which one triages them with the least time, memory and tokens, how accurate its triage is, which agent is the bottleneck, and how model size and the number of agents change that cost, before you deploy it.

HIGH-LEVEL CONCEPT

“A per-agent fuel-economy test for LLM triage agents.”

Unfair Advantage

  • Per-agent instrumentation: time, memory and tokens measured inside each agent step, for any number of agents, not only end to end
