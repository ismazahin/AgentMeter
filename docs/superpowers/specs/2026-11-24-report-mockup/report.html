Verdict

Qwen2.5 3B uses 35% less working memory than Llama 3.2 3B. Speed and token use are a tie.

Both models ran the same four-agent triage on the same 20 network flows, one after the other on the same GPU. A difference only counts when it holds up statistically.

In plain words

35%less

Qwen needs less working memory

While answering, Qwen2.5 3B used 157 MB on top of its weights and Llama 3.2 3B used 243 MB. That extra room matters when inputs get long or several agents share one GPU.

0.9 sfaster, not proven

Speed is too close to call

Llama answered a flow in 9.89 s on average and Qwen in 10.80 s. With only 20 flows that gap could be chance. On the slowest flows Llama stayed clearly quicker, 10.86 s against 12.99 s.

<5%apart

Tokens, cost and energy match

Both models wrote about 3,400 tokens per flow and drew the same power. Running 1,000 flows costs $0.70 to $0.77 either way, so neither model saves money.

Which one to pick

Pick Qwen2.5 3B if

GPU memory is tight, you plan longer inputs, or you want to run more agents on the same card. It also has the higher overall efficiency score, 46.87 against 43.00.

Pick Llama 3.2 3B if

People wait on each answer and slow outliers hurt. Its slowest 5% of flows finished about 2 s sooner, so it feels steadier in use.

To settle the speed question, run the same pair again on 100 or more flows. Small gaps need more flows before they count.

How to read the charts

Shorter bar winsEvery chart says if lower or higher is better. Most measures are costs, so the shorter bar is the better result.
BestThe gap is realA Best tag means the difference passed a statistical test, or is larger than 5%. You can rely on it.
TieThe gap may be noiseA Tie means the two results are within 5%, or the test could not rule out chance. Treat the models as equal there.

Keep in mind

Where the time goes, agent by agent

Each flow passes through four agents in turn. This bar shows how long each one took for Qwen2.5 3B, on average per flow.

perceive 3.26 s
reason 4.06 s
act 3.20 s
Perceive30%reads the flow
Reason38%explains it
Decide2.5%picks a label
Act30%writes the action
8.9%of all tokens are hand-offs, where an earlier agent's answer is sent again to the next agent. That is about 303 tokens per flow, an estimate.

Reason takes the most time because it writes the longest answer. Giving it a smaller token limit is the change most likely to speed up the whole pipeline. Decide is almost free, since it only picks a label.
