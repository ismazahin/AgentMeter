What it measures

Five numbers for every agent and every flow, so you can pick a model that fits your GPU and your budget.

Latency
Seconds per flow and per agent, with the slow tail (p95, p99) and warm-up kept apart.
GPU memory
Peak VRAM, split into model weights and the working memory each run adds on top.
Tokens
What each agent reads and writes, including the context re-sent at every hand-off.
Cost
Dollars per 1,000 flows at the GPU's hourly price, projected to your volume.
Energy
Watt-hours per flow, read from the GPU while the pipeline runs.

How a benchmark runs

Three steps from a traffic file to a verdict you can defend.

  1. Bring your traffic

    Upload a CSV or PCAP, import one from a link, or reuse a prepared set. AgentMeter picks a balanced sample of flows for you.

  2. Pick one or two models

    Start from the five study models, or try any of 16 more from Hugging Face. Each card shows its size and how much GPU memory it needs at 4-bit.

  3. Read the verdict

    Watch the run live, then get a session with the head-to-head verdict, a weighted ranking, per-agent detail and a PDF report.

A real result

Qwen2.5-3B-Instruct is more resource-efficient than Llama-3.2-3B-Instruct: 35.5% less working VRAM, and a tie on latency and tokens.

Built to be fair

A comparison is only useful if both models had the same chance.

  • Same quantization

    Every model loads at the same 4-bit NF4, verified on the GPU before it can be picked.

  • Ties are called ties

    A difference only wins when the statistics support it. Otherwise the verdict says the models are tied.

  • One transparent score

    Models are ranked with Simple Additive Weighting. You can change the weights and see how the order moves.

  • Demo results are labelled

    Without a GPU, AgentMeter runs a simulation and marks every number as not a real measurement.
