# SEO audit: AgentMeter public site (2026-11-23)

Input: the `web/` folder of the repository (not the live site). Findings, highest impact first.

| # | Issue | Severity | Type | Fix |
|---|---|---|---|---|
| 1 | Homepage title is the brand only (`<title>AgentMeter</title>`) | HIGH | DECISION | Put the chosen search phrase first, e.g. `LLM GPU Efficiency Benchmark for Multi-Agent Pipelines \| AgentMeter`. Decide first whether search traffic matters at all. |
| 2 | `web/landing.html` is an orphan second homepage with the same title; no canonical tag anywhere | HIGH | DECISION | Delete `landing.html` unless still used. Add `<link rel="canonical" href="https://agentmeter.pages.dev/">` to `index.html` (use the custom domain if one is bought). |
| 3 | `app.html` (title `AgentMeter`) and `analysis.html` are indexable login shells | MEDIUM | MECHANICAL | `<meta name="robots" content="noindex">` in both heads (not in `_headers`, which `scripts/csp_headers.py` regenerates). |
| 4 | No `robots.txt`, no `sitemap.xml` | MEDIUM | MECHANICAL | Add both; sitemap lists `/` and `/docs/index.html`. |
| 5 | Meta description is 183 characters (cut at about 155) | LOW | MECHANICAL | Shorter: "Benchmark how efficiently open-source LLMs run a four-agent pipeline on a GPU: latency, VRAM, tokens, cost and energy per agent and per flow." |
| 6 | `docs/index.html` has no link back to the homepage | LOW | MECHANICAL | Add `<a href="../">AgentMeter home</a>`. |
| 7 | No structured data | LOW | MECHANICAL | `WebApplication` JSON-LD with values matching the visible text; no ratings or prices. Re-run `scripts/csp_headers.py`. |
| 8 | H2s are statements, not searcher questions | LOW | DECISION | Rephrase two or three as questions if informational traffic is wanted. |
| 9 | No Open Graph tags | LOW | MECHANICAL | `og:title`, `og:description`, `og:url`, `og:type`. |

**The one thing:** #2 and #3 (canonical, remove or noindex duplicates). #1 next, once the target audience is decided.

**Not checked (needs data):** live headers and redirects (`curl -I` on production and `staging.agentmeter.pages.dev`),
Search Console Performance and Pages reports, Core Web Vitals, the competing results for the chosen query.
